(１)モジュール構成図

UI処理部のモジュール構成図を以下に示す．

\[_コンポーネント内部をモジュール（Cで言えば関数,Javaならクラス）分解し，（主に呼出し関係に基づき）モジュール構成図を作る，Javaならクラス図_\]
---存在するモジュール---
AuthController : W1/W3のログイン画面からの入力を受け取り、認証要求をC2に送出し、認証結果に応じてセッション確立・エラ表示・画面遷移を行う。
属性: sessionManager, apiClient
メソッド: login(credentials), adminLogin(credentials), handleAuthResult(result)

SessionManager : JWT/Bearerトークンおよび現在ユーザ情報を保持し、トークン付与・有効性チェック・クリア等のセッション管理を担う。
属性: jwtToken, currentUserId, expiresAt
メソッド: storeToken(token), getToken(), isAuthenticated(), clear()

APIClient : サーバとの共通REST通信ラッパー。`SessionManager` からトークンを取得して `Authorization` ヘッダを付与し、エラーハンドリングを統一する。
属性: baseUrl, defaultHeaders
メソッド: post(path, body), get(path, params), put(path, body), delete(path)

NavigationRouter : アプリ内の画面遷移を管理し、ビュー切替とパラメータ受渡しを行う。
属性: currentView
メソッド: navigateTo(view, params), goBack()

MainController / CommunityListController : W2（メイン画面）でのコミュニティ一覧の取得・表示・フィルタリング・選択イベントを扱うコントローラ。
属性: communities, userId, filter
メソッド: loadList(filter), refresh(), selectCommunity(id)

CommunityService : C3相当のコミュニティ関連CRUD操作を集約するドメインサービス。APIClientを介してサーバへリクエストを送る。
属性: apiClient
メソッド: fetchList(params), fetchDetail(id), create(data), update(id,data), delete(id)

CommunityDetailController : W5（詳細画面）の表示ロジックを担当し、IDから詳細データを取得して画面に反映する。
属性: community, communityService
メソッド: loadDetail(id), openEdit(), requestDelete()

CommunityEditorController : W4（作成・編集画面）のフォーム管理、初期データ読込、バリデーション実行、保存要求送出を行う。
属性: formModel, validator, imageHandler
メソッド: loadForEdit(id), submit(), validate()

DeleteHandler : 削除確認ダイアログの表示、削除要求の送出、削除完了時の後処理（通知・一覧更新）を行う。
属性: confirmationDialog, communityService
メソッド: confirmDelete(id), executeDelete(id)

FormValidator : 各フォームの入力ルールを保持し、送信前の検証を実行して結果を返すユーティリティ。
属性: ルール集合
メソッド: validate(model) -> ValidationResult

SearchFilter / FilterManager : 検索キーワードや絞り込み条件を構築・適用し、一覧表示用のフィルタ処理を提供する。
属性: criteria
メソッド: apply(communities, criteria), buildFromInput(input)

ImageHandler / ImageUploader : 画像選択・リサイズ等の前処理およびサーバへのアップロード、保存パスの管理を行う。
属性: selectedFile, uploadPath
メソッド: select(file), upload(), getPath()

Notifier / ErrorDialog : 成功・失敗・確認などのユーザ通知およびダイアログ表示を行う共通モジュール。
メソッド: showSuccess(message), showError(message), showConfirm(message)

StateStore / ViewModel : 現在選択中のコミュニティID、一覧のキャッシュ、現在ユーザIDなどの共有状態を保持し、UI更新を支援する。
属性: selectedCommunityId, cachedLists
メソッド: set(key,value), get(key)

EventDispatcher : コンポーネント間の非同期イベント（例: 保存完了後の一覧更新）を仲介する。
メソッド: on(event, handler), emit(event, payload)

---終わり---
