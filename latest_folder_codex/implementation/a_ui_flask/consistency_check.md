# C1 UI処理部 整合性チェック

## 確認日

2026-06-30

## 結論

C1 UI処理部の画面、画面イメージ、主要な仕様記述の整合を確認した。
カテゴリ条件による絞り込みは、要求仕様書・外部設計書・内部設計書に記載があるため、C1側では検索フォーム内のカテゴリ条件として残す。
一方で、仕様にないカテゴリ専用パネルやデザイン切替ナビは画面から削除した。

## 修正した点

- W2メイン画面は、検索キーワード入力とカテゴリ条件プルダウンだけを検索条件として表示する。
- カテゴリ専用パネル、表示切替ナビを削除した。
- 連絡先の独立入力欄を削除し、必要な連絡先はコミュニティ内容欄に記入する形に統一した。
- C3保存ペイロードから独立した `contact` 項目を削除した。
- W4/W5の英語見出しを日本語に修正した。
- W1〜W5の最終画面イメージを現在の実装画面で更新した。
- `ui_images/final_screen_images/screen_image_spec_check.md` を現在の画面に合わせて更新した。
- 内部設計書のC1画像入力表現を、実装に合わせて「画像URL入力欄」「画像URL」に修正した。
- 参照されていない古い `*-Yudai-PC.html` テンプレートを削除した。

## C1実装の確認結果

- W1/W3はGoogleログインボタン、認証エラー表示、パスワード欄なしの構成で整合している。
- W2はコミュニティ名、カテゴリ、概要、画像、更新日時、詳細ボタン、新規作成ボタン、検索キーワード、カテゴリ条件を表示する。
- W4はコミュニティ名、カテゴリ、概要、コミュニティ内容、画像URL、保存、キャンセル、入力エラー表示を扱う。
- W5はコミュニティ名、カテゴリ、概要、コミュニティ内容、画像、作成日時、更新日時、編集、削除を表示する。
- C3未接続時は仮データを表示し、C3接続時は `auth_token` と検索条件を送信する。
- C3の `id` は画面側の `community_id`、`image_path` は画面側の `image_url` として扱う。
